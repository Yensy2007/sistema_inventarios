# Sistema de Gestión de Inventarios (POO)

Este repositorio contiene dos versiones del sistema de inventarios desarrolladas como parte de la asignatura de Programación Orientada a Objetos.

---

## 📁 Estructura del Proyecto

### 🔹 Tarea 1 – Sistema básico con POO
Ruta:
tarea 1/sistema_inventarios/

Implementa un sistema de inventarios utilizando clases en Python sin persistencia en archivos.

Incluye:
- Clase Producto
- Clase Inventario
- main.py para ejecutar el sistema
- Operaciones CRUD básicas

---

### 🔹 Tarea 2 – Sistema con persistencia en archivos
Ruta:
tarea 2/sistema_inventarios_archivos/

Extiende el sistema anterior agregando almacenamiento en archivo de texto.

Incluye:
- Lectura y escritura en inventario.txt
- Manejo de archivo para guardar productos
- Clases organizadas en módulos
- main.py para ejecución

---

## ▶ Cómo ejecutar

Entrar a la carpeta correspondiente y ejecutar:

python main.py
