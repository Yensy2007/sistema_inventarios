# 📦 Sistema de Gestión de Inventarios (Python)

Este proyecto implementa un Sistema de Gestión de Inventarios en Python utilizando
Programación Orientada a Objetos (POO), manejo de archivos y un menú interactivo por consola.

---

## 🛠️ Funcionalidades

- Agregar productos al inventario
- Eliminar productos por ID
- Actualizar cantidad o precio
- Buscar productos por nombre
- Mostrar todos los productos
- Guardar datos en archivo de texto
- Cargar datos automáticamente al iniciar el programa
